Compasso Casco

A fonte do Compasso nasce do mesmo pixel da tartaruga e do céu do site. Cada canto exposto é arredondado como um casco, e os traços inclinados ganham uma emenda a 45° para não se partirem.

Como ela é construída

Uma grade de pixels vira contorno vetorial. O desenho de cada letra mora em fonts/build-casco.py.

  • ■
    Pixel de 100 unidadesA fonte tem 1000 unidades por em, então cada pixel é um décimo do tamanho do texto. Em 20 px, cada pixel vira 2 px de tela.
  • ◜
    Cantos maciosSó os cantos expostos são arredondados. Os cantos internos ficam retos, e a letra continua legível.
  • /
    Emenda a 45°Pixels que se tocam só pela diagonal ganham uma ponte em losango, como a curva do casco no logo.

Como usar

Copie a pasta fonts/ e declare a família uma vez.

@font-face {
  font-family: "Compasso Casco"; font-weight: 100 599; font-display: swap;
  src: url("fonts/CompassoCasco-Regular.woff2") format("woff2");
}
@font-face {
  font-family: "Compasso Casco"; font-weight: 600 900; font-display: swap;
  src: url("fonts/CompassoCasco-Bold.woff2") format("woff2");
}
.numero { font-family: "Compasso Casco", ui-monospace, monospace; font-weight: 700; font-size: 40px; }

Dica: use tamanhos múltiplos de 10 px (20, 30, 40…) e letter-spacing: 0. Para mudar uma letra, edite a grade no gerador e rode python build-casco.py.
